# Shareware Vision

Oooh! Remember that funky weird april fools snapshot from 2019?! Well here's a reimplementation of its 3D ultra-defined graphics, billboarded entities and sound crunchiness for the modern versions. Pretty sick, i know;

### Quick questions

* **Is it _100%_ accurate?** Well no, because I want the game to be at least a tiny bit playable.
* **Why isn't there any config?** There will be! I'm still trying to figure out the shader part of it! :)
* **Does it work with shaders and/or resource packs?** Yes, it does!
